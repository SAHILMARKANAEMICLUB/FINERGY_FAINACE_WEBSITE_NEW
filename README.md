# Finergy Finance website

A responsive finance landing page built with the Next.js App Router, React, and TypeScript. The page includes responsive navigation, solution cards, an interactive EMI estimate, FAQs, and contact information.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Next.js, usually `http://localhost:3000`.

The EMI calculator is illustrative only. Product terms, eligibility, and availability should be confirmed before launch. Contact information comes from Finergy Finance partner details in the EMI Club project.
